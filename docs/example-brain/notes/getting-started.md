# Getting Started with Flip

Welcome to your Flip brain! This note explains the basics.

## Core Concepts

**Brain**: A folder containing all your knowledge, organized in subfolders.

**Notes**: Markdown files with YAML frontmatter for metadata.

**Tasks**: Checkboxes with structured metadata for tracking work.

## Daily Workflow

1. **Morning**: Open today's journal with `flip journal`
2. **During the day**: Create notes, add tasks
3. **Evening**: Review tasks with `flip task browse`

## Useful Commands

```bash
flip journal          # Today's journal
flip note "Title"     # New note
flip task browse      # Browse tasks
flip brain check      # Health check
```
