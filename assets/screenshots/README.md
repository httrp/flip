# Screenshots

This folder contains visual demonstrations of flip features.

## Files

- **flip-menu.png** - Interactive CLI menu showing main commands
- **vscode-integration.png** - VS Code task integration and gang view

These are referenced in the main README and docs. To add or update screenshots:

1. Take a screenshot of the feature
2. Save as PNG in this directory
3. Update the relevant markdown files with the image path

## Tips for Good Screenshots

- Use a terminal with good contrast (dark background recommended)
- Keep window size consistent (~90x28 chars for terminal)
- Highlight relevant UI elements clearly
- Consider adding annotations for clarity
